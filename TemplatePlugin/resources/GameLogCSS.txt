/* System lines only (the non-player-chat entries: death lines,
   killed-by lines, verdicts, day/night headers and the like) get a
   black text outline, so colored text stays readable on a colored
   line background -- a red role mention on a red death line (e.g.
   "destroyed by a Berserker") being the case that prompted this.
   The outline is deliberately NOT global: a body-wide stroke
   (v30) thinned out and washed out the summary's gradient names.
   A shadow is used here instead of a stroke: on a black line
   background it is invisible, so unaffected lines look exactly
   as before. Gradient spans inside a system line get no shadow
   (shadows show through their transparent fill) and instead a
   drop-shadow halo, which is painted behind the glyphs and so
   cannot bleed into them. */
.sysline {
  text-shadow: -1px 0 #000000, 1px 0 #000000, 0 -1px #000000, 0 1px #000000;
}
/* All chat text: the transcript is wrapped in a chatlog div, so
   the outline inherits into every chat form -- player chat, dead
   chat, special channels and system lines alike. Gradient spans
   get the drop-shadow halo instead, as with sysline; gradient
   author names are exempted in their own <style> rule (see
   ChatNameStyleHtml), since their gradient arrives via a class
   rule rather than an inline style. Note the honest limit: on a
   black line background a black shadow is invisible, so ordinary
   chat looks unchanged -- the outline only ever shows where a
   line background is colored. The summary, wills and tooltips
   sit outside the wrapper and are untouched. */
.chatlog {
  text-shadow: -1px 0 #000000, 1px 0 #000000, 0 -1px #000000, 0 1px #000000;
}
