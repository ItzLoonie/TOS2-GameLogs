# Game Logs
An updated version of Game Logs, accounting for newer features.<br>
Based off TubaAntics' original Game Logs mod.

- Supports Flexible Factions
- Role list preview so you know exactly what was played
- Easily accessible viewing of causes of death
- Winner and alive data
- Visualized Town Traitor and VIP status
- New lines in wills and death notes, because they didn't exist for some reason lol
- "Winning Faction"
- Bug fixes
- Color in chat logs
- Fancy UI support
