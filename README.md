# Game Logs
An updated version of Game Logs, accounting for newer features.
Based off TubaAntics' original Game Logs mod.

- Supports Flexible Factions
- Role list preview so you know exactly what was played
- Easily accessible viewing of causes of death
- Winner and alive data
- Visualized Town Traitor and VIP status
- New lines in wills and death notes, because they didn't exist for some reason lol
- "Winning Faction"
- Bug fixes
- Color in chat logs
- Fancy UI support



## AI Disclosure
AI was used to decompile and clean the Game Logs mod file into something that could be compiled, since mod decompilation is a mess.
No code changes were made by the AI that weren't necessary by the decompilation.
Everything after that was human with minor AI assistance.

Don't worry, this isn't vibecoded.
